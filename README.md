# Proyecto Data Engineer

Proyecto de práctica para aprender Linux, Bash scripting y automatización de pipelines.

## Tecnologías utilizadas
- Linux
- Bash
- Git
- GitHub

## Estructura del proyecto

```text
raw/         -> datos originales
processed/   -> datos procesados
logs/        -> logs automáticos
scripts/     -> scripts Bash
notebooks/   -> notebooks Jupyter
outputs/     -> reportes y resultados
```

## Funcionalidades
- Automatización con cron jobs
- Procesamiento básico de archivos
- Uso de argumentos Bash
- Generación de logs
